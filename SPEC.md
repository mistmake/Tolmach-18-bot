# Telegram-бот «Лексикон XVIII века» — техническое задание

**Назначение:** интерактивный словарь устаревших и заимствованных слов XVIII века, с карточками, цитатами из источников и квизами.

**КРИТИЧНО:** этот документ — единственный источник истины. Не добавляй функции, которых здесь нет. Не «улучшай» структуру данных. Не меняй имена полей. Не предлагай альтернативы — реализуй ровно то, что написано.

---

## 1. Стек

- Python 3.11+
- `aiogram` версии 3.x (НЕ 2.x, синтаксис разный)
- `python-dotenv` для токена
- Хранение данных: JSON-файлы (никаких БД)
- Никаких внешних API, никакого LLM
- Состояние пользователя (счёт квиза) — в памяти процесса (dict), без персистентности. При перезапуске — обнуляется.

`requirements.txt`:
```
aiogram>=3.4.0
python-dotenv>=1.0.0
```

## 5. Функционал бота

### 5.1. Команды

| Команда | Действие |
|---|---|
| `/start` | Приветствие + главное меню (inline-клавиатура) |
| `/help` | То же что `/start`, без приветствия |
| `/word` | Случайное слово — полная карточка |
| `/categories` | Меню категорий → список слов → карточка |
| `/quiz` | Меню режимов квиза → игра |
| `/era` | Лонгрид «Об эпохе» с пагинацией |
| `/about` | Авторы, источники, литература |
| `/stats` | Текущий счёт пользователя в квизах (за сессию) |

Текстовые сообщения, не являющиеся командами, игнорируются с подсказкой «Используйте меню или команды. /help — справка.»

### 5.2. Главное меню (под `/start`)

Inline-клавиатура, 2 столбца:
```
[ 🎲 Слово дня ]      [ 📖 Категории ]
[ 🎯 Квиз ]           [ 📚 Об эпохе ]
[ ℹ️ Об авторах ]
```

### 5.3. Команда `/word` и кнопка «🎲 Слово дня»

Выбирает случайное слово из `words.json` (`random.choice`) и показывает полную карточку. Формат карточки — см. раздел 6.1.

Под карточкой — inline-клавиатура:
```
[ 🎲 Ещё одно ]  [ 🏠 В меню ]
```

### 5.4. Команда `/categories` и кнопка «📖 Категории»

**Уровень 1:** показать клавиатуру с 4 категориями (по одной кнопке в строке):
```
🏛 Государство и общество
⚔️ Военное и морское дело
🎭 Светская жизнь и этикет
📚 Наука, искусство, литература
```

`callback_data` для категорий: `cat_state_society`, `cat_military`, `cat_social_life`, `cat_culture`.

**Уровень 2:** при нажатии на категорию — показать список всех слов категории (13–15 штук в зависимости от категории) как нумерованный список + клавиатуру с номерами для выбора.

Текст сообщения:
```
🏛 <b>Государство и общество</b>

1. канцелярист
2. артикул
3. прожект
4. указ
5. социетет
...

Нажмите номер для подробностей.
```

Клавиатура: цифры по 5 в строке (3 строки по 5 для 15 слов, 2 строки по 5 + 1 строка для 13–14 слов) + кнопка «⬅️ К категориям».

`callback_data` для слов: `word_{id}`.

**Уровень 3:** при нажатии на номер — полная карточка слова (формат — раздел 6.1) + клавиатура:
```
[ ⬅️ К списку ]  [ 🏠 В меню ]
```

`callback_data` для возврата: `back_to_cat_{category}`.

### 5.5. Команда `/quiz` и кнопка «🎯 Квиз»

**Шаг 1.** Показать клавиатуру выбора режима:
```
🔤 Угадай значение
💬 Угадай слово по цитате
⏳ Сохранилось или устарело?
```

`callback_data`: `quiz_meaning`, `quiz_quote`, `quiz_today`.

**Шаг 2.** Логика каждого режима — раздел 7.

**Шаг 3.** После ответа — показ результата + кнопки:
```
[ ▶️ Следующий вопрос ]  [ 🛑 Завершить ]
```

При завершении — показ итогового счёта.

### 5.6. Команда `/era` и кнопка «📚 Об эпохе»

Прочитать `data/about_era.md`, разбить по `\n---\n` на страницы. Показывать одну страницу с навигацией:

```
[ ⬅️ ]  Стр. X из Y  [ ➡️ ]
[ 🏠 В меню ]
```

`callback_data`: `era_page_{N}`.

Текущая страница хранится в `callback_data`, без FSM.

### 5.7. Команда `/about` и кнопка «ℹ️ Об авторах»

Статический HTML-текст. См. раздел 6.4.

### 5.8. Команда `/stats`

Показать текущий счёт пользователя в квизах (за сессию):
```
📊 <b>Ваша статистика</b>

Всего вопросов: {total}
Правильных: {correct}
Точность: {percent}%
```

Если квиз не играли: «Вы ещё не играли в квиз. Начать: /quiz»

## 6. Форматы вывода

Везде `parse_mode="HTML"`.

### 6.1. Полная карточка слова

```
📜 <b>{word}</b> ({stress})

📖 <b>Значение в XVIII в.:</b>
{meaning}

🌍 <b>Происхождение:</b>
{origin}

💬 <b>Из источника:</b>
<i>«{quote}»</i>
— {source}

⚙️ <b>Связь с реформой:</b>
{reform_link}

⏳ <b>Судьба слова сегодня:</b>
{today}
```

### 6.2. Вопрос квиза «Угадай значение»

```
🔤 <b>Вопрос {N}</b>

Что означало слово <b>«{word}»</b> в XVIII веке?
```

+ inline-клавиатура с 4 вариантами (каждый — отдельная кнопка в новой строке). Варианты — короткие формулировки (см. раздел 7.1).

### 6.3. Вопрос квиза «Угадай слово по цитате»

```
💬 <b>Вопрос {N}</b>

Прочитайте цитату из источника XVIII века:

<i>«{quote_with_blank}»</i>
— {source}

Какое слово было пропущено?
```

+ 4 кнопки со словами.

### 6.4. Вопрос квиза «Сохранилось или устарело»

```
⏳ <b>Вопрос {N}</b>

Слово <b>«{word}»</b> означало в XVIII в.:
<i>{meaning}</i>

Сохранилось ли оно в современном русском с тем же значением?
```

+ 2 кнопки: «✅ Сохранилось» / «❌ Устарело или изменилось».

### 6.5. Ответ на вопрос квиза

При правильном ответе:
```
✅ <b>Верно!</b>

{краткое пояснение из карточки слова}

📊 Счёт: {correct}/{total}
```

При неправильном:
```
❌ <b>Неверно.</b>

Правильный ответ: <b>{correct_answer}</b>

{краткое пояснение}

📊 Счёт: {correct}/{total}
```

### 6.6. Итог квиза (после нажатия «🛑 Завершить»)

```
🏁 <b>Квиз завершён</b>

Правильных: {correct} из {total}
Точность: {percent}%

{вердикт по точности — см. ниже}
```

Вердикты:
- 90–100%: «🏆 Превосходно! Вы знаете эпоху на уровне историка.»
- 70–89%: «👍 Хороший результат. Эпоха вам знакома.»
- 50–69%: «📚 Есть пробелы. Загляните в /categories.»
- 0–49%: «🤔 Эпоха ещё ждёт вашего изучения. Начните с /era.»

## 7. Логика квизов (раздел `core/quiz_logic.py`)

### 7.1. Режим «Угадай значение» (`quiz_meaning`)

**Генерация вопроса:**
1. Выбрать случайное слово из `words.json` — это правильный ответ.
2. Взять его `meaning` как правильный вариант.
3. Взять 3 случайных `meaning` других слов как неправильные.
4. Перемешать 4 варианта.
5. Запомнить индекс правильного.

**Длина вариантов:** если `meaning` слишком длинное для inline-кнопки (Telegram ограничивает ~64 символов на текст кнопки), сократить до первых 50 символов + «…». Полное значение показывается после ответа.

**Проверка:** при нажатии — сверка с правильным индексом.

### 7.2. Режим «Угадай слово по цитате» (`quiz_quote`)

**Генерация вопроса:**
1. Выбрать случайное слово.
2. Взять его `quote`. Найти само слово в цитате (без учёта регистра, со словоформами — простая эвристика: если в цитате нет точного вхождения леммы, попробовать первые 4–5 букв слова + `*`). Если не нашлось — выбрать ДРУГОЕ слово (повторять до 10 попыток).
3. Заменить найденное вхождение на `_____`.
4. 4 варианта — это правильное слово + 3 случайных слова из той же категории.
5. Перемешать.

**Важно:** если слова из одной категории слишком мало (меньше 4), брать дистракторы из соседних категорий.

### 7.3. Режим «Сохранилось или устарело» (`quiz_today`)

**Генерация вопроса:**
1. Выбрать случайное слово.
2. Показать `word` + `meaning`.
3. Бинарный ответ: «Сохранилось» / «Устарело или изменилось».
4. Правильный ответ определяется по полю `today`:
   - Если в `today` есть слова **«вышло»**, **«устарело»**, **«не употребляется»**, **«архаизм»**, **«историзм»**, **«изменило значение»**, **«сместилось»** → правильный ответ «❌ Устарело или изменилось».
   - Иначе → «✅ Сохранилось».

**Альтернатива (если первая эвристика покажется ненадёжной):** добавить в `words.json` дополнительное булево поле `survived_today`. **НО** — это раздувает схему данных. Используй эвристику по ключевым словам. **В стартовых данных раздела 10 я гарантирую, что эвристика работает на всех 55 записях.**

### 7.4. Хранение состояния

Глобальный `dict` в `core/storage.py`:

```python
# user_id -> dict
user_state: dict[int, dict] = {}

# Каждая запись:
# {
#   "quiz_mode": "meaning" | "quote" | "today" | None,
#   "correct": int,
#   "total": int,
#   "current_question": dict | None,  # детали текущего вопроса
# }
```

Функции:
- `get_state(user_id) -> dict` — возвращает или создаёт запись.
- `reset_quiz(user_id)` — обнуляет счёт и режим.
- `record_answer(user_id, is_correct: bool)` — инкрементирует счётчики.

## 8. Структура `bot.py`

```python
import asyncio
import logging
from aiogram import Bot, Dispatcher
from aiogram.client.default import DefaultBotProperties
from config import BOT_TOKEN
from handlers import start, words, quiz, info

async def main():
    logging.basicConfig(level=logging.INFO)
    bot = Bot(
        token=BOT_TOKEN,
        default=DefaultBotProperties(parse_mode="HTML"),
    )
    dp = Dispatcher()
    
    dp.include_router(start.router)
    dp.include_router(words.router)
    dp.include_router(quiz.router)
    dp.include_router(info.router)
    
    await dp.start_polling(bot)

if __name__ == "__main__":
    asyncio.run(main())
```

**Примечание:** в aiogram 3.7+ `parse_mode` передаётся через `DefaultBotProperties`, а не как параметр `Bot()`. Используй именно эту форму.

## 9. Обработка ошибок

1. `words.json` не загружается / повреждён → `bot.py` падает при старте с понятной ошибкой.
2. `about_era.md` отсутствует → при `/era` отвечать «Раздел временно недоступен», бот продолжает работать.
3. Callback с устаревшими данными (например, после перезапуска) → отвечать «Сессия устарела, начните заново через /start», использовать `callback.answer()` и удалять клавиатуру.
4. Любое исключение в хендлере логировать, пользователю отвечать «Произошла ошибка. /start — начать заново.»

```markdown
📚 <b>Русский язык XVIII века: эпоха европеизации</b>

XVIII век — это не «старый русский». Это эпоха языковой революции, проведённой указами и регламентами. За сто лет — от воцарения Петра I в 1689 г. до смерти Екатерины II в 1796 г. — русский лексикон был перепрошит несколькими волнами реформ.

В нашем словаре собрано 55 слов, каждое из которых — след конкретной реформы. Это не случайная выборка: вместе они образуют карту культурных и государственных преобразований эпохи.

---

⚙️ <b>Волна 1. Пётр I: государство, армия, флот</b>

Пётр I не просто заимствовал слова — он создавал на их месте новые понятия, которых в русской культуре не существовало.

В государственной сфере: <b>ассамблея, сенат, коллегия, прожект, регламент, фискал, артикул, табель, мануфактура</b> — это имена новых учреждений и социальных практик.

В военно-морской сфере: <b>баталия, виктория, ретирада, фортеция, цейхгауз, обер-офицер, рекрут, бомбардир, фрегат, драгун, инфантерия, кампания</b> — лексика регулярной армии и флота европейского образца.

Источники заимствования: немецкий, голландский, польский. Французский (через который пришли латинизмы) начнёт доминировать позже, при Елизавете и Екатерине.

---

🎭 <b>Волна 2. Светская культура и французская мода</b>

Если Пётр насаждал европейские формы сверху, то при Елизавете и особенно Екатерине II произошёл вторичный, более глубокий слой европеизации — на уровне дворянского быта, чувств и моды.

Появились <b>политес, плезир, амур, конфузия, куртаг, променад, галантный, мадригал, маскарад, парик, камзол, кавалер</b>. Французский становится языком российской аристократии — иногда настолько, что русский остаётся только для общения с прислугой.

Лексика этого слоя — почти целиком из французского. Это не язык канцелярии, а язык салона, бала, любовной записки.

---

📐 <b>Волна 3. Ломоносов и теория трёх штилей</b>

Параллельно с лексическими заимствованиями шла нормализация литературного языка. М.В. Ломоносов в работе «Предисловие о пользе книг церковных» (1758) предложил теорию трёх штилей: высокого (для од и героических поэм), среднего (для научной прозы, дружеских писем) и низкого (для комедий, басен).

К высокому штилю отнесены церковнославянизмы и греко-латинизмы: <b>ода, элоквенция, гистория, натура, философ, пиитика, эклога, грация</b>. К среднему — нейтральная лексика. К низкому — народно-разговорные слова.

Поэтому многие слова из нашего словаря — это не просто «старые слова», а лексика конкретного стилистического слоя, искусственно поддерживаемая нормой эпохи.

---

🔬 <b>Что это даёт для понимания истории?</b>

Через язык XVIII в. видны три вещи, неочевидные из учебников:

1. <b>Реформы были массовыми и принудительными.</b> Не «Пётр привёз слово ассамблея» — а «Пётр указом обязал дворян посещать ассамблеи каждые две недели». За каждым словом — практика.

2. <b>Европеизация шла слоями.</b> Сначала военно-административный (немецко-голландский), потом светский (французский), потом литературный (через церковнославянизмы и латинизмы). Слои не сменяли друг друга, а наслаивались.

3. <b>Многие слова XVIII в. живы, но изменили значение.</b> «Конфуз» сузился со «всякого замешательства» до «смущения». «Натура» отступила перед «природой». «Штиль» из литературного термина стал морским. Это карта культурных сдвигов в одной таблице.
```
