# Лексикон XVIII века — Telegram-бот

Интерактивный словарь устаревших и заимствованных слов русского языка XVIII века.
Учебный проект по курсу «История России», ФКН ВШЭ, 2026.

## Возможности

- 55 слов с цитатами из исторических источников
- 4 тематические категории
- 3 режима квиза
- Аналитический раздел «Об эпохе»

## Запуск

1. Создать бота через @BotFather, получить токен.
2. Скопировать `.env.example` в `.env`, вставить токен.
3. `pip install -r requirements.txt`
4. `python bot.py`
